CentOS 9 安装 MySQL 8

1. 卸载 MariaDB 2. 安装官方源 3. 安装 MySQL 4. 启动服务 5. 获取密码 6. 修改密码
1

卸载系统自带的 MariaDB

CentOS 9 默认自带 MariaDB，会和 MySQL 产生冲突，必须先卸载干净。

# 检查是否安装了 MariaDB
rpm -qa | grep mariadb

# 卸载所有 MariaDB 相关包
sudo dnf remove -y mariadb-libs
2

安装 MySQL 官方 Yum 源

添加 MySQL 官方软件源，这样才能安装到最新的 MySQL 8 版本。

# 下载并安装 MySQL 8 官方源
sudo dnf install -y https://dev.mysql.com/get/mysql80-community-release-el9-4.noarch.rpm

# 导入 GPG 密钥（解决安装时的签名验证问题）
sudo rpm --import https://repo.mysql.com/RPM-GPG-KEY-mysql-2023

# 禁用 Google Chrome 源（解决国内访问报错问题）
sudo dnf config-manager --set-disabled google-chrome
3

安装 MySQL 服务端

安装 MySQL 社区版服务端，这是核心程序。

sudo dnf install -y mysql-community-server
4

启动服务并设置开机自启

启动 MySQL 服务，并设置为开机自动启动，这样服务器重启后 MySQL 也会自动运行。

# 启动 MySQL 服务
sudo systemctl start mysqld

# 设置开机自启
sudo systemctl enable mysqld

# 检查服务状态（显示 active (running) 即为成功）
sudo systemctl status mysqld
5

获取初始 root 密码

MySQL 第一次启动时会自动生成一个临时的 root 密码，保存在日志文件中。

sudo grep 'temporary password' /var/log/mysqld.log

输出结果中最后面的一串字符就是临时密码，例如：tiM@t1gp2rE

6

登录并修改 root 密码

使用临时密码登录 MySQL，然后修改为你自己的密码。

# 使用临时密码登录（把下面的临时密码换成你自己的）
mysql -uroot -p'你的临时密码'

# 修改 root 密码（必须包含大小写字母、数字和特殊符号）
ALTER USER 'root'@'localhost' IDENTIFIED BY 'Root@123456';

# 刷新权限
FLUSH PRIVILEGES;

# 退出 MySQL
EXIT;

恭喜！MySQL 8 已经成功安装在你的 CentOS 9 系统上了！
